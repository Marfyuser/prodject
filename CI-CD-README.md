# CI/CD Отладка для Windows + WSL Ubuntu

## 🎯 Описание
Система локальной отладки CI/CD, которая позволяет тестировать изменения на Ubuntu через WSL перед push в git.

## 📋 Требования
- Windows 10/11 с WSL2
- Ubuntu в WSL (уже установлен)
- PowerShell
- Git

## 🚀 Быстрый старт

### 1. Первоначальная настройка
```powershell
# Запустите основной скрипт настройки
.\ci-cd-debug.ps1
```

Этот скрипт:
- ✅ Проверит доступность WSL Ubuntu
- 📁 Создаст временную директорию в WSL
- 📋 Скопирует проект в WSL
- 🔧 Установит и настроит nginx
- 🌐 Запустит веб-сервер
- 🧪 Протестирует доступность сайта

### 2. Рабочий процесс разработки

#### Тестирование изменений
```powershell
# После внесения изменений в код
.\update-ci-cd.ps1
```

#### Автоматическое тестирование перед push
```powershell
# Git автоматически запустит тестирование перед push
git add .
git commit -m "Ваши изменения"
git push  # ← Здесь сработает pre-push hook
```

### 3. Остановка тестирования
```powershell
# Когда закончили работу
.\stop-ci-cd.ps1
```

## 📁 Структура файлов

```
prodject/
├── ci-cd-debug.ps1      # Основной скрипт настройки
├── update-ci-cd.ps1     # Скрипт обновления проекта
├── stop-ci-cd.ps1       # Скрипт остановки (создается автоматически)
├── .git/hooks/pre-push  # Git hook для автоматического тестирования
├── nginx-site/          # Основной проект
└── CI-CD-README.md      # Этот файл
```

## 🔧 Конфигурация

### Nginx конфигурация
Скрипт автоматически создает конфигурацию nginx с:
- ✅ Gzip сжатие
- 📦 Кэширование статических файлов
- 🔒 Безопасные настройки
- 📱 Поддержка всех типов файлов

### Временные директории
- 📁 Создается в `/tmp/ci-cd-test-YYYYMMDD-HHMMSS/`
- 🗑️ Автоматически очищается при остановке
- 🔄 Обновляется при каждом изменении

## 🧪 Тестирование

### Что тестируется
- ✅ Доступность веб-сервера
- ✅ Корректность nginx конфигурации
- ✅ Загрузка статических файлов
- ✅ Работа JavaScript и CSS

### Как проверить вручную
1. Запустите `.\ci-cd-debug.ps1`
2. Откройте браузер по адресу `http://[WSL_IP]`
3. Проверьте все функции сайта

## 🐛 Устранение неполадок

### WSL Ubuntu не найден
```powershell
# Проверьте статус WSL
wsl --list --verbose

# Запустите Ubuntu если не запущен
wsl -d Ubuntu
```

### Nginx не запускается
```powershell
# Проверьте статус nginx в WSL
wsl -d Ubuntu -e bash -c "sudo systemctl status nginx"

# Перезапустите nginx
wsl -d Ubuntu -e bash -c "sudo systemctl restart nginx"
```

### Сайт недоступен
```powershell
# Проверьте IP адрес WSL
wsl -d Ubuntu -e hostname -I

# Проверьте конфигурацию nginx
wsl -d Ubuntu -e bash -c "sudo nginx -t"
```

## 🔄 Workflow разработки

### Типичный рабочий день:
1. **Утром**: `.\ci-cd-debug.ps1` - запуск тестовой среды
2. **Во время разработки**: `.\update-ci-cd.ps1` - после каждого изменения
3. **Перед коммитом**: `git add . && git commit -m "..."` - автоматическое тестирование
4. **Вечером**: `.\stop-ci-cd.ps1` - остановка тестовой среды

### Преимущества:
- 🚀 Быстрое тестирование изменений
- 🔒 Предотвращение push'а сломанного кода
- 🐧 Тестирование в Linux окружении
- 💻 Удобная разработка в Windows

## 📝 Логи и отладка

### Просмотр логов nginx
```powershell
wsl -d Ubuntu -e bash -c "sudo tail -f /var/log/nginx/access.log"
wsl -d Ubuntu -e bash -c "sudo tail -f /var/log/nginx/error.log"
```

### Просмотр статуса сервисов
```powershell
wsl -d Ubuntu -e bash -c "sudo systemctl status nginx"
```
